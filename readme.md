# 设计文档

## 技术栈

前端：VUE3 组合式API + Element UI + ECharts（图表）

后端：SpringBoot + Redis（缓存）

数据库：PostgreSQL

## 项目初始化

### 前端初始化

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### 后端初始化

```sh
redis-server
```
